# アプリケーションディレクトリ構造

このドキュメントでは、モバイルオーダーアプリケーションのディレクトリ構造について説明します。プロジェクトの各ディレクトリとその役割を以下に示します。

## ディレクトリ構造

- **app/**: アプリケーションのルートディレクトリ。すべてのソースコードとリソースが含まれています。
  - **components/**: UI コンポーネントを格納するディレクトリ。アプリケーション内で再利用可能な UI 要素を定義します。
    - `BottomNav.tsx`: 画面下部に表示されるナビゲーションバーコンポーネント。
    - `Button.tsx`: 汎用的なボタンコンポーネント。スタイルと機能を統一するために使用。
    - `CartItem.tsx`: カート内のアイテムを表示するためのコンポーネント。
    - `LayoutConverter.tsx`: タイトルとコンテンツをまとめる枠組みを提供するコンポーネント。レイアウトを統一的に扱うために使用。
    - `Menu.tsx`: メニューを表示するためのコンポーネント。
    - `Modal.tsx`: 確認モーダルや通知を表示するためのコンポーネント。
    - `QuantityControl.tsx`: 商品の数量を増減させるためのコントロールコンポーネント。
  - **constants/**: 定数を格納するディレクトリ。アプリケーション全体で使用される定数を一元管理します。
    - `api.ts`: API エンドポイントなどの定数を定義。
  - **data/**: 静的なデータやモックデータを格納するディレクトリ（現在は空）。
  - **features/**: アプリケーションの主要な機能をモジュール化して格納するディレクトリ。各機能は独立したサブディレクトリに分かれています。
    - **cart/**: カート機能に関連するファイル。
      - **component/**: カート関連のコンポーネント。
        - `CartItem.tsx`: カートアイテムを表示するコンポーネント。
      - **hooks/**: カート関連のフック。
        - `useCart.ts`: カートの状態管理を行うカスタムフック。
    - **menu/**: メニュー機能に関連するファイル。
      - **component/**: メニュー関連のコンポーネント。
        - `Menu.tsx`: メニューを表示するコンポーネント。
      - **types/**: メニュー関連の型定義。
        - `item.ts`: メニューアイテムの型定義。
        - `menu.ts`: メニュー全体の型定義。
    - **order/**: 注文機能に関連するファイル。
      - **hooks/**: 注文関連のフック。
        - `useOrder.ts`: 注文の状態管理を行うカスタムフック。
      - **routes/**: 注文関連のルート。
        - `api_.order.route.tsx`: 注文処理のための API エンドポイント。
      - **types/**: 注文関連の型定義。
        - `order.ts`: 注文の型定義。
      - **utils/**: 注文関連のユーティリティ。
        - `order.server.ts`: 注文処理のためのサーバーサイドユーティリティ。
  - **hooks/**: カスタム React フックを格納するディレクトリ。アプリケーション固有のロジックをカプセル化し、再利用可能なフックとして提供するために使用します。
    - `useCart.ts`: カートの状態管理を行うカスタムフック。セッションストレージからカートデータを取得し、数量の更新機能を提供します。
  - **routes/**: アプリケーションのルート（ページ）を定義するディレクトリ。Remix のルーティングに基づいています。
    - `_index.tsx`: アプリケーションのメインページ。ユーザーが最初にアクセスするページで、アプリケーションのエントリーポイントとして機能します。
    - `admin._index.tsx`: 管理者向けのメインページ。管理者ダッシュボードとして機能し、システムの概要や重要な情報を確認できます。注文状況やユーザー情報を一元的に管理することが可能です。
    - `admin.account.tsx`: 管理者アカウント管理ページ。管理者アカウントの設定や情報を管理できます。プロフィールの編集やパスワードの変更など、セキュリティに関連する操作が行えます。
    - `api_.order.route.tsx`: 注文処理のための API エンドポイント。注文データを処理し、サーバーサイドでの注文管理をサポートします。
    - `cart.tsx`: ショッピングカートページ。ユーザーが選択したアイテムを確認し、注文を確定する前に数量を調整したり、アイテムを削除したりできます。
    - `menu._index.tsx`: メニューリストページ。利用可能なメニューアイテムの一覧を表示し、ユーザーが選択してカートに追加できるようにします。
    - `menu.$itemId.tsx`: 個々のメニューアイテム詳細ページ。特定のメニューアイテムの詳細情報を表示し、ユーザーが数量を選択してカートに追加できるようにします。
    - `orders.tsx`: 注文履歴ページ。ユーザーが過去に行った注文の履歴を確認できます。
    - `qr.tsx`: QR コードスキャンページ。QR コードをスキャンして特定のテーブルや注文情報を関連付けるためのページです。
  - **types/**: TypeScript の型定義を格納するディレクトリ。アプリケーション全体で使用される型を一元管理します。このディレクトリには、アプリケーションのデータ構造やインターフェースを定義するファイルのみを配置し、コードの再利用性と型安全性を高めるために使用します。
    - `cartItem.ts`: カートアイテムの型定義。
    - `item.ts`: メニューアイテムの型定義。
    - `session.ts`: セッション情報の型定義。
  - **utils/**: ユーティリティ関数やヘルパーを格納するディレクトリ。アプリケーションのロジックをサポートします。
    - **business/**: ビジネスロジックに関連するユーティリティ。
      - `fetchJson.ts`: API リクエストを簡素化するための汎用的なユーティリティ関数。JSON データを型安全に取得。
      - `session.server.ts`: セッション管理のためのサーバーサイドユーティリティ。
    - **domain/**: ドメイン固有のユーティリティ。
      - `api.server.ts`: API 通信のためのサーバーサイドユーティリティ。
  - `entry.client.tsx`: クライアントサイドのエントリーポイント。
  - `entry.server.tsx`: サーバーサイドのエントリーポイント。
  - `root.tsx`: アプリケーションのルートコンポーネント。
  - `setupTests.ts`: テストのセットアップファイル。
  - `tailwind.css`: Tailwind CSS スタイルシート。

## 開発者向け情報

### Storybook セットアップとデプロイ

Storybook を UI コンポーネントの開発とテストに使用しています。以下の設定と手順で、Storybook をローカル環境で実行したり、Vercel にデプロイしたりできます。

- **ローカルでの実行**: `npm run storybook` コマンドを使用して、Storybook をローカル環境で起動します。これにより、コンポーネントのプレビューとテストが可能です。
- **ビルドとデプロイ**: Storybook をビルドするには `npm run build-storybook` を実行します。ビルドされたファイルは `storybook-static` ディレクトリに出力されます。

### API キーの管理

セキュリティを向上させるため、microCMS API キー (`MICROCMS_API_KEY`) はソースコードにハードコードせず、`.env` ファイルで環境変数として管理しています。アプリケーションは `process.env.MICROCMS_API_KEY` を介してこの値にアクセスします。

### API リクエスト

API リクエストには `fetchJson` ユーティリティ関数を使用しています。この関数は一貫した方法で API リクエストを行い、環境変数から API キーを取得してリクエストヘッダーに設定します。`fetch` を直接使用する代わりに、この関数を利用してコードの再利用性と保守性を高めています。

## 管理者機能

このアプリケーションには、管理者向けの機能が含まれています。管理者向けの機能には以下のものが含まれます：

- **管理者ダッシュボード** (`admin._index.tsx`)：管理者向けのメインページで、システムの概要や重要な情報を確認できます。注文状況やユーザー情報を一元的に管理することが可能です。
- **アカウント管理** (`admin.account.tsx`)：管理者アカウントの設定や情報を管理できます。プロフィールの編集やパスワードの変更など、セキュリティに関連する操作が行えます。

詳細な情報や管理者機能の使い方については、アプリケーション内の管理者セクションを参照してください。

## まとめ

このディレクトリ構造は、Remix フレームワークの規約に基づいており、コードの整理と再利用性を高めるために設計されています。各ディレクトリは特定の役割を持ち、アプリケーションの機能を明確に分離しています。これにより、開発者は必要なファイルを見つけやすく、コードの保守性が向上します。
