# モバイルオーダーアプリケーション

これは、使いやすさと視覚的一貫性を重視して設計されたモバイルオーダーアプリケーションです。

## セットアップ

このプロジェクトをローカル環境でセットアップする手順は以下の通りです。

### 1. 環境変数の設定

プロジェクトのルートディレクトリに`.env`ファイルを作成し、Supabaseプロジェクトの情報を設定してください。

```
SUPABASE_URL="あなたのSupabaseプロジェクトURL"
NEXT_PUBLIC_SUPABASE_ANON_KEY="あなたのSupabase匿名キー"
```

### 2. Supabaseデータベースの設定

このアプリケーションはSupabaseの**行レベルセキュリティ（RLS）**を利用します。

開発を始めるにあたり、データベースに適切なポリシーを設定する必要があります。開発用のサンプルポリシーが `supabase/policies.sql.sample` に用意されています。

SupabaseダッシュボードのSQLエディタで、このファイルの内容を実行してください。

**【重要】**
このサンプルポリシーは、開発を容易にするための緩やかな設定です。本番環境で利用する際は、認証情報（`auth.uid()`など）を用いて、ユーザーが自身のデータにのみアクセスできるように、より厳格なポリシーに書き換える必要があります。

## 管理者機能

このアプリケーションには、管理者向けの機能が含まれています。管理者向けの機能には以下のものが含まれます：

- **管理者ダッシュボード**：管理者向けのメインページで、システムの概要や重要な情報を確認できます。
- **アカウント管理**：管理者アカウントの設定や情報を管理できます。

詳細な情報や管理者機能の使い方については、アプリケーション内の管理者セクションを参照してください。
