# アプリケーションディレクトリ構造

このドキュメントでは、モバイルオーダーアプリケーションのディレクトリ構造について説明します。プロジェクトの各ディレクトリとその役割を以下に示します。

## ディレクトリ構造

- **app/**: アプリケーションのルートディレクトリ。すべてのソースコードとリソースが含まれています。
  - **components/**: UI コンポーネントを格納するディレクトリ。アプリケーション内で再利用可能な UI 要素を定義します。
    - `BottomNav.tsx`: 画面下部に表示されるナビゲーションバーコンポーネント。
    - `Button.tsx`: 汎用的なボタンコンポーネント。スタイルと機能を統一するために使用。
    - `LayoutConverter.tsx`: タイトルとコンテンツをまとめる枠組みを提供するコンポーネント。レイアウトを統一的に扱うために使用。
    - `Menu.tsx`: メニューを表示するためのコンポーネント。
    - `Modal.tsx`: 確認モーダルや通知を表示するためのコンポーネント。
    - `QuantityControl.tsx`: 商品の数量を増減させるためのコントロールコンポーネント。
  - **constants/**: 定数を格納するディレクトリ。アプリケーション全体で使用される定数を一元管理します。
    - `api.ts`: API エンドポイントや API キーなどの定数を定義。
  - **data/**: 静的なデータやモックデータを格納するディレクトリ（現在は空）。
  - **hooks/**: カスタム React フックを格納するディレクトリ。アプリケーション固有のロジックをカプセル化し、再利用可能なフックとして提供するために使用します。
    - `useCart.ts`: カートの状態管理を行うカスタムフック。セッションストレージからカートデータを取得し、数量の更新機能を提供します。
  - **routes/**: アプリケーションのルート（ページ）を定義するディレクトリ。Remix のルーティングに基づいています。
    - `_index.tsx`: アプリケーションのメインページ。
    - `admin._index.tsx`: 管理者向けのメインページ。
    - `admin.account.tsx`: 管理者アカウント管理ページ。
    - `api_.order.route.tsx`: 注文処理のための API エンドポイント。
    - `cart.tsx`: ショッピングカートページ。
    - `menu._index.tsx`: メニューリストページ。
    - `menu.$itemId.tsx`: 個々のメニューアイテム詳細ページ。
    - `orders.tsx`: 注文履歴ページ。
    - `qr.tsx`: QR コードスキャンページ。
  - **types/**: TypeScript の型定義を格納するディレクトリ。アプリケーション全体で使用される型を一元管理します。このディレクトリには、アプリケーションのデータ構造やインターフェースを定義するファイルのみを配置し、コードの再利用性と型安全性を高めるために使用します。
    - `cartItem.ts`: カートアイテムの型定義。
    - `item.ts`: メニューアイテムの型定義。
    - `session.ts`: セッション情報の型定義。
  - **utils/**: ユーティリティ関数やヘルパーを格納するディレクトリ。アプリケーションのロジックをサポートします。
    - **business/**: ビジネスロジックに関連するユーティリティ。
      - `fetchJson.ts`: API リクエストを簡素化するための汎用的なユーティリティ関数。JSON データを型安全に取得。
      - `session.server.ts`: セッション管理のためのサーバーサイドユーティリティ。
    - **domain/**: ドメイン固有のユーティリティ。
      - `api.server.ts`: API 通信のためのサーバーサイドユーティリティ。
  - `entry.client.tsx`: クライアントサイドのエントリーポイント。
  - `entry.server.tsx`: サーバーサイドのエントリーポイント。
  - `root.tsx`: アプリケーションのルートコンポーネント。
  - `setupTests.ts`: テストのセットアップファイル。
  - `tailwind.css`: Tailwind CSS スタイルシート。

## まとめ

このディレクトリ構造は、Remix フレームワークの規約に基づいており、コードの整理と再利用性を高めるために設計されています。各ディレクトリは特定の役割を持ち、アプリケーションの機能を明確に分離しています。これにより、開発者は必要なファイルを見つけやすく、コードの保守性が向上します。
